# Veyl of the Kingmaker

One use raises item Class by exactly one, up to Class 15. Existing affixes, tiers and bounds, rolls, rarity, quality, implicits, base stats, pearl cost and lock stay unchanged. The new cap applies to future crafting.

Classes 1-12 unlock two tiers per Class. Classes 13/14/15 unlock T27/T30/T33. The entry stays hidden until first acquisition in the current adventure log and remains visible at zero balance. Discovery is save-scoped through ARPG_VEYL_KINGMAKER_ACQUIRED. Native identity I_VEYL_KINGMAKER remains stable.

It is excluded from ordinary drops and current boss/story bundles. Its late-game award location remains undecided. The distributable includes no test stock or save edits. See Tier-scaling-guide.md and docs/Player-guide.md.
